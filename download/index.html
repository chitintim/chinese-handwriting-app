墨字帖

電子墨水平板的抄經練字 App · Handwriting practice (抄心經) for e-ink tablets

開啟網頁版 (不用安裝)

下載 墨字帖Download moxie.apk (Android)

若下載無反應：長按連結 → 下載連結，或開啟 GitHub Releases 頁面
If the download does nothing: long-press the button and choose Download link, or open the GitHub Releases page.

目前版本 build 231e9c14da · 版本號以 Releases 為準

安裝 Install

  1. 下載：點上面的按鈕，下載 moxie.apk。
    Tap the button and download moxie.apk.
  2. 允許安裝：打開下載的檔案；若系統詢問，請允許瀏覽器或檔案管理員「安裝未知來源」(未知來源) 的 App，再按「安裝」。
    Open the file; if asked, allow installing from unknown sources for your browser or file manager, then tap Install.
  3. 打開：安裝完成後按「開啟」，或在桌面找到「墨字帖」。
    Tap Open, or find 墨字帖 in your apps.

更新：之後有新版時，下載並直接安裝即可，會覆蓋舊版，抄寫進度和資料都會保留。
Updates install over the old version and keep all your data.

此 App 可完全離線使用，也不會上傳任何資料；只有在檢查更新（每天最多一次，或在「設定」手動）時才連到 GitHub，新版本會在 App 內提示並可直接更新。Works offline and uploads nothing; it only contacts GitHub to look for updates (at most once a day, or manually in Settings) and can install the update itself.

網頁版與 App 是同一份程式，內容相同；App 可離線使用，且不需瀏覽器。
The web version and the app are the same code; the app works offline without a browser.
