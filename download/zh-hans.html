墨字帖

电子墨水平板的抄经练字 App · Sutra-copying and handwriting practice for e-ink tablets

打开网页版 (不用安装)

下载 墨字帖Download moxie.apk (Android)

若下载无反应：长按链接 → 下载链接，或打开 GitHub Releases 页面
If the download does nothing: long-press the button and choose Download link, or open the GitHub Releases page.

目前版本 build 4edda642c6 · 版本号以 Releases 为准

安装 Install

  1. 下载：点上面的按钮，下载 moxie.apk。
    Tap the button and download moxie.apk.
  2. 允许安装：打开下载的文件；若系统询问，请允许浏览器或文件管理员「安装未知来源」(未知来源) 的 App，再按「安装」。
    Open the file; if asked, allow installing from unknown sources for your browser or file manager, then tap Install.
  3. 打开：安装完成后按「打开」，或在桌面找到「墨字帖」。
    Tap Open, or find 墨字帖 in your apps.

更新：之后有新版时，下载并直接安装即可，会覆盖旧版，抄写进度和数据都会保留。
Updates install over the old version and keep all your data.

此 App 可完全脱机使用，也不会上传任何数据；只有在检查更新（每天最多一次，或在「设置」手动）时才连到 GitHub，新版本会在 App 内提示并可直接更新。Works offline and uploads nothing; it only contacts GitHub to look for updates (at most once a day, or manually in Settings) and can install the update itself.

网页版与 App 是同一份程序，内容相同；App 可脱机使用，且不需浏览器。
The web version and the app are the same code; the app works offline without a browser.
