Install

  1. Tap the button and download moxie.apk.
  2. Open the file; if asked, allow installing from unknown sources for your browser or file manager, then tap Install.
  3. Tap Open, or find 墨字帖 in your apps.

Updates install over the old version and keep all your data.

Works offline and uploads nothing; it only contacts GitHub to look for updates (at most once a day, or manually in Settings) and can install the update itself.

The web version and the app are the same code; the app works offline without a browser.
